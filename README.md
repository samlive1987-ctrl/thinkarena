# ThinkArena — Prototype v0.1

A responsive, single-page front-end prototype for the ThinkArena multi-AI debate product.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Current capabilities
- Responsive dark premium interface
- Debate topic input and example prompts
- Three participant cards (ChatGPT, Gemini, Grok)
- Sample debate output and preliminary Judge summary
- Reset/new debate interaction

## Important limitation
This is a front-end prototype only. It does NOT call OpenAI, Gemini, or xAI APIs. The displayed debate responses are illustrative demo text, not generated by live models.

## Next engineering milestone
Build a backend that:
1. Stores provider API keys as server-side secrets.
2. Calls each provider's current supported API independently.
3. Sends anonymized/controlled debate context for rebuttal rounds.
4. Applies usage limits, cost controls, timeouts, and error handling.
5. Produces a judge summary with citations/evidence where available.

Do not put API keys in browser JavaScript or commit secrets to source control.
